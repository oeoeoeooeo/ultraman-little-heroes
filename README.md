## 立即玩

線上版使用 Chrome 或 Safari 開啟網址即可。離線版由 `python3 scripts/build.py` 產生 **「小英雄基地.html」**，所有圖片、語音、程式與樣式都包在同一個檔案裡，可以離線玩，不用安裝、不用登入。產物不加入公開 Git，避免每次提交重複的大型檔案。也可以開啟開發用的 `index.html`，但需保留旁邊的 `assets` 資料夾、`style.css` 和 `app.js`。

英雄大百科與對戰選角可依經典、平成、新生代、最新英雄分類，也可搜尋中文名、英文名或年份。最新分組包含布雷薩（2023）、雅克（2024）、奧米加（2025）與 Teo（2026）。沒有專屬變身器的英雄仍能選角對戰，變身器猜謎與翻牌只使用有道具的角色，並避免共用道具造成多重答案。

首頁可選「弟弟模式」「哥哥模式」「兄弟一起」。建議第一次由爸爸媽媽陪著點一次，認識按鈕和鍵盤。

## v1.8.0 宇宙飛行救援

首頁主入口直接出發。可選一人駕駛或兄弟一起，各自選英雄與難度；輕鬆每波 4 秒、挑戰每波 2.8 秒，較快完成的玩家等待夥伴。完整規格見 [宇宙飛行救援設計](SPACE_RESCUE.md)。

1. 穿越星海：四波三航道，左右移動接住星光。
2. 隕石救援：四波航道，可對準隕石發射光線，或左右閃開。長按發射能連射；光線沿發射時的航道前進。
3. 基地守門戰：每人對準 ◎ 命中三次，自己的力量會保留。全員集滿後，各自按「準備放必殺技」；先準備的會等夥伴，一起發光救回基地。

哥哥 A／S／D、弟弟 J／K／L，依序是左、發射、右。單人也能用 ←／空白鍵／→；平板直接按各自的大按鈕。Esc、切到背景、視窗失焦、旋轉或開啟家長說明都會暫停，需手動繼續。碰撞由護盾保護，不扣已收集的星光，沒有淘汰或付費續關。

完整通關獲得 24 顆星星，星光與射擊表現最多再加 12 顆，只結算一次；中途離開不發通關獎。保留原本的「雙人星際飛行」，首頁共十一款遊戲。這是從商品外觀延伸的原創玩法，未取得原機的實際遊戲或程式，不宣稱還原原機。

## v1.7.0 兄弟守護隊

首頁主入口直接出發「城市光盾救援」。先選「兄弟一起」或「一人輪流玩」，每人可選既有英雄與自己的難度；哥哥預設挑戰，弟弟預設輕鬆。各自變身、完成一次練習，再完成巴士、列車、太空基地三站救援。

守護員照順序按上／下光盾，探索員照順序找星星、菱形或圓球。輕鬆模式一直保留線索，挑戰模式先看 3 秒，再回想 2～3 步；答錯會重新顯示，提示不扣星星。兩份任務完成才能過站，完成者的進度保留；下一站可交換工作。最後各自按「準備好了」，都亮燈才發射合體光線，沒有同時按的要求。完成獲得 24 顆星星，不重複計獎。

哥哥 A／S／D，弟弟 J／K／L；平板按自己的圖形大按鈕，Esc 暫停。背景或旋轉暫停後手動繼續；一人可依序操作兩位英雄。難度、英雄與進度只存本機，沿用既有素材及歡呼，沒有新增 API 或付費服務。

已完成 DOM 流程、實際瀏覽器操作、雙指觸控與離線建置；代表性截圖已檢視。正式網址完整測試通過。尚未在實體 iPad 或兒童上試玩；完整範圍見 [QA_REPORT.md](QA_REPORT.md)。

## v1.6.0 雙指同樂、街機與動腦

雙人對戰、變身、反應特訓與飛行按鈕按每根手指獨立處理。兩人可同時按；一人放手不會停止另一人的長按，取消觸控、暫停或離開會清除操作。觸控立即生效，避免之後的模擬點擊重複出招。只有遊戲操作鈕關閉瀏覽器拖曳、縮放、選字與長按選單，其他地方可滑動；作業系統保留的多指手勢仍由裝置設定決定。

「雙人星際飛行」有各自三條航道，左右閃隕石、接星光；兩人都接到有合作連擊，碰到隕石有護盾，沒有淘汰。每趟 12 波，可選每波 3.2／2.4／1.7 秒；哥哥 A／D、弟弟 J／L，也可同時觸控大按鈕。Esc、畫面暫停、切到背景都可停止飛行；回來手動繼續。

「光能接線」每次隨機產生三座可解的基地；點管道順時針轉 90 度，把左上角太陽入口接到右下角右側旗幟出口。光走到哪裡就亮到哪裡，可復原一步、重來、逐步提示；不限時間。弟弟與兄弟模式為 3×3，哥哥後兩關為 4×4。兩人可以一起討論輪流轉，也可各自玩。提示不扣星星，完成三關才領獎。

首頁共有十一款遊戲；既有星星、貼紙、英雄組合與六項基本任務徽章條件保留。新玩法是本遊戲原創設計，不是官方劇情。尚未以實體 iPad 或真人兒童試玩驗證主觀趣味。

## v1.5.0 活力音效與兄弟反應特訓

首頁新增「兄弟反應特訓」，原有雙人選角畫面也有入口。預設勇氣隊，可選暖身 8 回合、勇氣 10 回合、超能 12 回合。各自看訊號出招、輪流接力、雲朵假訊號與四步記憶接力帶來不同挑戰；哥哥用 A／S，弟弟用 L／K，也能觸控大按鈕。Esc 暫停，離開分頁會自動暫停。

哥哥與弟弟各有反應目標，較快完成可得節奏星，慢慢完成仍有冒險星星；答錯可重試，不扣生命。通關顯示本次平均反應與最佳連續合作，可保留難度再玩一次。這些是本遊戲的原創玩法與數值，未做真人兒童試玩。

九段本機歡呼全數重新製作，語速 195～208、明確句間停頓、音量正規化與音樂短句；音樂與說話分開，沒有同時蓋住字句。操作音效改用分層泛音與音高變化，連點會替換前一個音效，避免越疊越大聲。音檔網址加上版號，全部隨遊戲提供，不呼叫語音 API。讀題使用裝置中文語音，語速 1.02、音高 1.18，實際聲音依裝置而定；未人工聆聽驗證音色。

## 平板、聲音與光線修正

選角與怪獸清單改用整頁捲動，平板導覽改為頁首排列。對戰在平板採戰場與控制面板並排，手機戰場隨操作保留在上方，發射時看得到光線。主要文字與按鈕放大至 16px 以上，說明與次要資訊以 14px 以上為原則。新增變身登場光環、蓄光環、光束核心與命中擴散環，發射時短暫壓暗背景，支援減少動態效果與暫停。

答對歡呼重新製作，開頭預留空白、兩句之間留停頓；提示音、歡呼與答案朗讀不再同時啟動。先播完歡呼，再隔 150ms 朗讀答案；換題、靜音或離開會取消待播聲音。猜謎讀題改成中性問題，不讀原始提示、選項或道具名稱；答案僅在選對後公布。

## v1.4.0 玩家體驗升級

首頁新增「星星救援旅程」，直接用最近的英雄組合出發。三站依序在森林收集三顆光之星、海岸找三次腳印、宇宙辨認三次分身，完成線索後才能發射光線。每一站沒有倒數限制，答錯可以慢慢再試；每次旅程的夥伴組合會變化。完成整段旅程獲得單人 20／雙人 25 顆星星。

對戰、救援與旅程小站完成後，會收藏對應的怪獸貼紙；貼紙簿在「我的小成就」，共 30 位夥伴。重複任務不增加重複貼紙，沒有抽卡或付款。未完成整趟旅程而離開時，已收集貼紙保留，旅程重新開始。

滑鼠或觸控可長按攻擊約 0.3 秒開始自動集氣，放開、暫停、離開畫面時停止。鍵盤按住 A／L 也能集氣。兄弟模式中，自己滿 4 格後多按一下，可送夥伴 1 格能量，每人每場一次。手機控制鈕改為兩人並排，能量與必殺技加入更清楚的畫面回饋。細節見 [玩家體驗檢視](UX_REVIEW.md)。

## 型態與怪獸冒險

選英雄後可選型態與 30 位怪獸／夥伴；對戰按 `D` 換哥哥的型態、`J` 換弟弟的型態。力量型每次攻擊 3 點（一般 2 點），速度型縮短集氣間隔，守護型延長護盾，慈愛型在救援時加強友善光。這些數值是適合幼兒的遊戲平衡設計。

怪獸分成突進、電流、重裝、飛行、分身、鑽地等挑戰。重裝與飛行可用對應型態取得額外能量；分身與鑽地要點亮著星星的位置。答錯、來不及按都不扣生命。皮古蒙、卡內貢、Pucchi 與三位流星怪獸夥伴安排成友善任務，Pucchi 送甜甜圈、卡內貢送虛擬硬幣，不涉及付款。

必殺技可點選，光線、光輪、爆發、友善之光有不同演出。沒有已確認專屬招式的角色使用明示的「遊戲練習招式」，不把它收錄成官方技能。

九段「活力教練」歡呼由 Mac 本機的繁體中文 Flo 聲音產生並配製為 MP3。開發用重製方式見 `scripts/generate_audio.py`，一般玩家不需要執行。已做全部音檔解碼、播放及合成音效振幅檢查；歡呼後才朗讀答案，換題、靜音、暫停或切換分頁會停止聲音。

## 操作

| 遊戲 | 操作 |
| --- | --- |
| 猜謎 | 點選答案，或按數字 `1`～`4`；答對後按「下一題」。 |
| 單人對戰 | `A`／`←` 攻擊、`S`／`↓` 護盾、`空白鍵` 必殺光線。 |
| 兄弟合作 | 哥哥 `A` 攻擊、`S` 護盾；弟弟 `L` 攻擊、`K` 護盾；兩人各集滿 4 格能量，按 `空白鍵` 發射。 |
| 暫停 | 按畫面「暫停」或 `Esc`。離開分頁會自動暫停，回來後手動繼續。 |
| 雙人飛行 | 哥哥 `A`／`D`、弟弟 `J`／`L` 左右移動，或按各自的大箭頭。 |
| 光能接線 | 點管道轉動，使用提示、復原、重來按鈕。 |
| 平板、手機 | 全部玩法都有畫面按鈕，可以直接觸控。 |

猜謎與接線不限時間；飛行有三段速度，但沒有淘汰懲罰。怪獸發出能量波時，試著開護盾；錯過時會收到光之國防護罩，繼續練習。完成對戰後，下次會輪替既有怪獸夥伴。

弟弟模式提供英雄圖片選項、比較直接的提示與自動讀題；哥哥模式增加選項、減少提示。型態題固定最多三個選項，來自同一位英雄。語音與音效可由右上角喇叭切換；歡呼語音隨遊戲附上；讀題與百科朗讀的中文聲音依裝置與瀏覽器而定。首次開啟時，先點任一遊戲讓瀏覽器允許音效。

## 開發與檢查

遊戲本體使用 HTML、CSS、JavaScript，無執行期依賴、無外部連線。字型使用實際裝置可用的 `Microsoft JhengHei`、`PingFang TC`、`Heiti TC` 等繁體中文字型，未內嵌微軟字型。

```sh
# 需要 Node.js 的開發驗證；一般遊玩不需要這些步驟
npm install
npm test

# 將目前的原始碼打包成單檔離線遊戲
python3 scripts/build.py

# 有瀏覽器啟動權限的環境才可執行
npx playwright install chromium webkit
npm run test:browser
node qa/tablet-webkit.cjs

# 選用：本機 HTTP 伺服器（另需環境允許開啟連接埠）
npm start
```

**本次已完成：** JavaScript 語法檢查、資產完整性檢查、六種基本遊戲及三種反應特訓難度的 DOM 互動測試（實際 click／keydown 事件），含難度、答錯重試、雙人變身、獨立集氣、護盾、暫停中光線停止結算、配對、九枚徽章、存檔、離開畫面取消延遲，以及切換分頁暫停。

**瀏覽器驗證：** 已由公開儲存庫的 GitHub Actions 執行 Chromium 與 WebKit，原始碼與正式網址完整測試均通過。WebKit 使用觸控裝置模擬與程式化整頁捲動，未在實體 iPad 上驗證。`qa/check.cjs` 檢查九種尺寸（320×740、390×844、844×390、834×1194、1024×768、1280×720、1366×768、1440×1100、1920×1080）、直橫向與全遊戲流程。代表性截圖已人工檢視，詳見 [上線驗證紀錄](QA_REPORT.md)。截圖以壓縮 Base64 放在免費 job log，不配置 artifact 儲存服務；語音聽感仍取決於孩子使用的裝置。手動執行工作流程時可填入 `game_url`，驗證實際線上站點且禁止第三方網路請求。
