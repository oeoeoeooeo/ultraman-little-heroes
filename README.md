# 光之國・小英雄基地

專為 4 歲與 6 歲小朋友製作的繁體中文超人力霸王互動遊戲。

**版本：v1.4.0（2026-10-15）**。首頁頁尾與側欄顯示版號，`version.json` 提供部署版本。

線上遊戲：[ultraman-heroes-base.web.app](https://ultraman-heroes-base.web.app)。公開原始碼：[oeoeoeooeo/ultraman-little-heroes](https://github.com/oeoeoeooeo/ultraman-little-heroes)。

## 立即玩

線上版使用 Chrome 或 Safari 開啟網址即可。離線版由 `python3 scripts/build.py` 產生 **「小英雄基地.html」**，所有圖片、語音、程式與樣式都包在同一個檔案裡，可以離線玩，不用安裝、不用登入。產物不加入公開 Git，避免每次提交重複的大型檔案。也可以開啟開發用的 `index.html`，但需保留旁邊的 `assets` 資料夾、`style.css` 和 `app.js`。

英雄大百科與對戰選角可依經典、平成、新生代、最新英雄分類，也可搜尋中文名、英文名或年份。最新分組包含布雷薩（2023）、雅克（2024）、奧米加（2025）與 Teo（2026）。沒有專屬變身器的英雄仍能選角對戰，變身器猜謎與翻牌只使用有道具的角色，並避免共用道具造成多重答案。

首頁可選「弟弟模式」「哥哥模式」「兄弟一起」。建議第一次由爸爸媽媽陪著點一次，認識按鈕和鍵盤。

## v1.4.0 玩家體驗升級

首頁新增「星星救援旅程」，直接用最近的英雄組合出發。三站依序在森林收集三顆光之星、海岸找三次腳印、宇宙辨認三次分身，完成線索後才能發射光線。每一站沒有倒數限制，答錯可以慢慢再試；每次旅程的夥伴組合會變化。完成整段旅程獲得單人 20／雙人 25 顆星星。

對戰、救援與旅程小站完成後，會收藏對應的怪獸貼紙；貼紙簿在「我的小成就」，共 30 位夥伴。重複任務不增加重複貼紙，沒有抽卡或付款。未完成整趟旅程而離開時，已收集貼紙保留，旅程重新開始。

滑鼠或觸控可長按攻擊約 0.3 秒開始自動集氣，放開、暫停、離開畫面時停止。鍵盤按住 A／L 也能集氣。兄弟模式中，自己滿 4 格後多按一下，可送夥伴 1 格能量，每人每場一次。手機控制鈕改為兩人並排，能量與必殺技加入更清楚的畫面回饋。細節見 [玩家體驗檢視](UX_REVIEW.md)。

## 六種小冒險

| 任務 | 怎麼玩 |
| --- | --- |
| 猜猜我是誰 | 看英雄圖片與提示，從 53 位英雄中認出角色。每輪 5 題。 |
| 型態猜猜看 | 從 55 種型態觀察配色與提示；選項都來自同一位英雄。每輪 5 題。 |
| 這是誰的變身器？ | 觀察變身器示意圖，選出它的主人。每輪 5 題。 |
| 變身！怪獸對戰 | 選英雄、拿出想像中的變身器、變身，再集氣發射必殺光線。 |
| 兄弟合體出任務 | 兩人各選一位英雄、各自變身，合作集氣發射合體光線。 |
| 英雄翻翻樂 | 找出英雄與他的變身器，配成一對。弟弟 4 組、哥哥 6 組。 |

另有五個百科分頁：53 位英雄、55 種型態、60 件變身器／力量道具／武器、90 招有來源的代表招式、30 隻怪獸。可聽故事、從圖鑑直接出任務，並收集九枚成就徽章。星星於完成任務後發放，紀錄存在目前瀏覽器的 localStorage，沒有帳號與雲端同步。

## 型態與怪獸冒險

選英雄後可選型態與 30 位怪獸／夥伴；對戰按 `D` 換哥哥的型態、`J` 換弟弟的型態。力量型每次攻擊 3 點（一般 2 點），速度型縮短集氣間隔，守護型延長護盾，慈愛型在救援時加強友善光。這些數值是適合幼兒的遊戲平衡設計。

怪獸分成突進、電流、重裝、飛行、分身、鑽地等挑戰。重裝與飛行可用對應型態取得額外能量；分身與鑽地要點亮著星星的位置。答錯、來不及按都不扣生命。皮古蒙、卡內貢、Pucchi 與三位流星怪獸夥伴安排成友善任務，Pucchi 送甜甜圈、卡內貢送虛擬硬幣，不涉及付款。

必殺技可點選，光線、光輪、爆發、友善之光有不同演出。沒有已確認專屬招式的角色使用明示的「遊戲練習招式」，不把它收錄成官方技能。

九段歡呼改用隨遊戲下載的「活力教練」聲音，在 Mac 本機用繁體中文 Flo 聲音產生，195 字速、輕微加速與音量正規化後存為 MP3。播放不呼叫語音 API。讀題與百科故事仍使用裝置的繁體中文語音，語速 1.03、音高 1.23；可在說明裡試聽、右上角靜音。切換頁面、背景或暫停會停止歡呼。未人工聆聽確認音色；已做音檔解碼、音量與播放測試。

## 操作

| 遊戲 | 操作 |
| --- | --- |
| 猜謎 | 點選答案，或按數字 `1`～`4`；答對後按「下一題」。 |
| 單人對戰 | `A`／`←` 攻擊、`S`／`↓` 護盾、`空白鍵` 必殺光線。 |
| 兄弟合作 | 哥哥 `A` 攻擊、`S` 護盾；弟弟 `L` 攻擊、`K` 護盾；兩人各集滿 4 格能量，按 `空白鍵` 發射。 |
| 暫停 | 按畫面「暫停」或 `Esc`。離開分頁會自動暫停，回來後手動繼續。 |
| 平板、手機 | 全部玩法都有畫面按鈕，可以直接觸控。 |

答錯不扣分、任務不設倒數時間、沒有遊戲結束懲罰。怪獸發出能量波時，試著開護盾；錯過時會收到光之國防護罩，繼續練習。完成對戰後，下次會輪替哥摩拉、小紫、小綠訓練怪獸。

弟弟模式提供英雄圖片選項、比較直接的提示與自動讀題；哥哥模式增加選項、減少提示。型態題固定最多三個選項，來自同一位英雄。語音與音效可由右上角喇叭切換；歡呼語音隨遊戲附上；讀題與百科朗讀的中文聲音依裝置與瀏覽器而定。首次開啟時，先點任一遊戲讓瀏覽器允許音效。

## 開發與檢查

遊戲本體使用 HTML、CSS、JavaScript，無執行期依賴、無外部連線。字型使用實際裝置可用的 `Microsoft JhengHei`、`PingFang TC`、`Heiti TC` 等繁體中文字型，未內嵌微軟字型。

```sh
# 需要 Node.js 的開發驗證；一般遊玩不需要這些步驟
npm install
npm test

# 將目前的原始碼打包成單檔離線遊戲
python3 scripts/build.py

# 有瀏覽器啟動權限的環境才可執行
npx playwright install chromium
npm run test:browser

# 選用：本機 HTTP 伺服器（另需環境允許開啟連接埠）
npm start
```

**本次已完成：** JavaScript 語法檢查、資產完整性檢查、六種完整遊戲流程的 DOM 互動測試（實際 click／keydown 事件），含難度、答錯重試、雙人變身、獨立集氣、護盾、暫停中光線停止結算、配對、九枚徽章、存檔、離開畫面取消延遲，以及切換分頁暫停。

**瀏覽器驗證：** 已由公開儲存庫的 GitHub Actions 執行 Chromium，正式網址的完整測試通過。`qa/check.cjs` 檢查九種尺寸（320×740、390×844、844×390、834×1194、1024×768、1280×720、1366×768、1440×1100、1920×1080）、直橫向與全遊戲流程。代表性截圖已人工檢視，詳見 [上線驗證紀錄](QA_REPORT.md)。截圖以壓縮 Base64 放在免費 job log，不配置 artifact 儲存服務；語音聽感仍取決於孩子使用的裝置。手動執行工作流程時可填入 `game_url`，驗證實際線上站點且禁止第三方網路請求。

## 安全與免費空間

使用全新隔離的 Firebase 傳統靜態 Hosting Spark 專案；不部署雲端函式、雲端資料庫、Cloud Run 或付費 App Hosting。只上傳 `dist` 的 98 個白名單靜態檔案。無前端 API 金鑰、付費 API、登入、分析追蹤或外部執行期依賴，並移除 Firebase 自動產生的閒置 API key。部署前查證未綁定帳單；完整範圍與限制見 [SECURITY.md](SECURITY.md)。
